# decoder-ffmpeg (local JNI build)

Media3's FFmpeg audio decoding extension, built inside this repository instead
of consuming a prebuilt AAR.

## Why this module exists

Media3 does not publish `androidx.media3:media3-decoder-ffmpeg` to Google
Maven. The previous integration used Jellyfin's community AAR
(`org.jellyfin.media3:media3-ffmpeg-decoder:1.9.0+1`), which is licensed
**GPL v3** and built on Media3 1.9.0. This module replaces it with:

- the FFmpeg extension wrapper classes vendored from **androidx/media 1.11.1**
  (Apache License 2.0, original headers retained), and
- `libffmpegJNI.so`, cross-compiled from the pinned FFmpeg source tree by
  `android/build-ffmpeg-jni.sh` with `--disable-gpl --disable-nonfree
  --disable-version3` (LGPL-2.1-or-later only).

The app still uses Media3's reflective `DefaultRenderersFactory` discovery, so
`FfmpegAudioRenderer` is picked up automatically (`EXTENSION_RENDERER_MODE_PREFER`)
when the native library loads. If it does not load, playback falls back to
platform MediaCodec and `FfmpegCapabilityProbe` reports `available=false`.

## Layout

| Path | Origin / role |
|---|---|
| `src/main/java/androidx/media3/decoder/ffmpeg/` | Vendored from androidx/media 1.11.1 `libraries/decoder_ffmpeg` (Apache 2.0) |
| `src/main/jni/ffmpeg_jni.cc` | Vendored JNI bridge, same source tag (Apache 2.0) |
| `src/main/jniLibs/arm64-v8a/libffmpegJNI.so` | Generated by `android/build-ffmpeg-jni.sh` (gitignored) |
| `.ffmpeg-build/` | Generated FFmpeg checkout and static libraries (gitignored) |

Only four wrapper classes are vendored: `FfmpegLibrary`, `FfmpegAudioDecoder`,
`FfmpegAudioRenderer`, and `FfmpegDecoderException`. The experimental video
renderer is intentionally omitted because this app plays audio only.

## Rebuilding the native library

```bash
bash android/build-ffmpeg-jni.sh            # build if missing
bash android/build-ffmpeg-jni.sh --clean    # rebuild FFmpeg from scratch
```

Gradle runs the same script from `:decoder-ffmpeg:buildFfmpegJni`, wired into
`preBuild`, so a normal `flutter build apk` produces the `.so` on first use.
Gradle tracks the FFmpeg tag, Android API, pinned NDK, ABI, script, and JNI
source as task inputs. The script fingerprints the source revision, configure
arguments, compiler/toolchain, enabled decoder set, and build recipe; static
archives are rebuilt when that fingerprint changes instead of trusting only
the presence of `libavcodec.a`.

Defaults: FFmpeg `n8.1.3`, arm64-v8a, Android API 27, decoders ALAC, DCA
(DTS/DTS-HD), TrueHD/MLP, and Vorbis. Opus is intentionally not built because
the target device's MediaCodec/CCodec Opus decoder handles it. Override the tag
with `FFMPEG_TAG=...` and run with `--clean` when changing it.
