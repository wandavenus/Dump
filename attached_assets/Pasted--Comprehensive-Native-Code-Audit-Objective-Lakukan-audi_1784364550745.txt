# Comprehensive Native Code Audit

## Objective

Lakukan audit menyeluruh terhadap seluruh kode native dan platform Android pada repository.

Target audit adalah menemukan seluruh bug, potensi crash, memory leak, race condition, dead code, code smell, masalah performa, security issue, serta peluang perbaikan arsitektur.

**Jangan melakukan perubahan kode apa pun. Fokus hanya pada audit dan pelaporan.**

---

# Scope

Audit seluruh source code berikut tanpa pengecualian:

## Native

- Seluruh file `.c`
- Seluruh file `.cpp`
- Seluruh file `.cc`
- Seluruh file `.cxx`
- Seluruh file `.h`
- Seluruh file `.hpp`
- Seluruh file `.hh`
- Seluruh file `.S`
- Seluruh file `.s`
- Seluruh file Assembly lain yang digunakan project

## Android

- Seluruh file `.kt`
- Seluruh file `.java`

## Build

Audit juga seluruh konfigurasi yang berhubungan dengan native:

- `CMakeLists.txt`
- `Android.mk`
- `Application.mk`
- Gradle Native Configuration
- NDK Configuration
- ABI Configuration
- JNI Configuration

# Validation Rules

Sebelum menyatakan sesuatu sebagai dead code atau tidak digunakan:

- Lakukan pencarian referensi di seluruh repository.
- Periksa seluruh include.
- Periksa seluruh import.
- Periksa JNI registration.
- Periksa dynamic loading.
- Periksa callback.
- Periksa virtual dispatch.
- Periksa template instantiation.
- Periksa macro expansion.
- Periksa penggunaan melalui reflection atau mekanisme dinamis lainnya.

Jika masih ada kemungkinan digunakan, tandai sebagai **Needs Manual Verification**, bukan sebagai dead code.

# Rules

- Jangan mengubah source code.
- Jangan menghapus file.
- Jangan membuat commit.
- Jangan melakukan refactor.
- Jangan memperbaiki bug secara otomatis.
- Fokus hanya pada audit dan pelaporan.
- Seluruh temuan harus dapat dibuktikan dari source code.
- Jangan membuat asumsi tanpa bukti.
- Jika terdapat keraguan terhadap suatu temuan, tandai sebagai **Needs Manual Verification**.
- Audit harus mencakup **100%** dari seluruh kode C, C++, Kotlin, Java, Assembly, JNI, dan konfigurasi native yang ada di repository.
