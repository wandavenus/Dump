# Scope

## 1. Dead Files

Safely remove validated dead files.

Examples include:

- empty files
- placeholder files
- obsolete wrappers
- unused debug files
- unused templates

Verify there are no remaining references.

---

## 2. Dead Methods

Remove validated unused methods.

Examples:

- exportPlaylist()
- clearHistory()
- getAlbumArtUri()

Only remove methods confirmed to have no callers.

---

## 3. Dead Classes

Remove validated unused classes.

Verify:

- no imports
- no runtime references
- no reflection usage

---

## 4. Dead Widgets

Remove validated unused widgets.

Examples:

- notif_icon
- placeholder widgets
- obsolete wrappers

Preserve public behavior.

---

## 5. Pure Re-export Files

Review export-only files.

If unnecessary:

- remove them

Otherwise:

- document their purpose.

Update imports safely.

---

## 6. Const Cleanup

Apply remaining validated const improvements.

Examples:

- Icon
- Padding
- SizedBox
- TextStyle
- constructors

Do not force const where runtime evaluation exists.

---

## 7. Naming Cleanup

Finish remaining validated naming issues.

Examples:

- cryptic variables
- inconsistent identifiers
- inconsistent filenames

Avoid unnecessary renames.

---

## 8. Documentation Cleanup

Remove obsolete comments.

Update outdated comments.

Document:

- public APIs
- native bridges

Avoid redundant comments.

---

## 9. Import Cleanup

Remove:

- unused imports

- obsolete exports

Sort imports consistently.

---

## 10. Analyzer Cleanup

Resolve remaining analyzer hints that are confirmed safe.
