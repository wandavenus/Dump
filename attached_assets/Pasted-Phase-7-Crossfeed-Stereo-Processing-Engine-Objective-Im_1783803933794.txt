Phase 7 — Crossfeed & Stereo Processing Engine

Objective

Implement a production-quality headphone Crossfeed processor inside the existing Native DSP Pipeline.

This phase improves stereo imaging for headphone listening.

Do NOT implement FFmpeg.

Do NOT modify the playback architecture.

Media3 remains the playback engine.

The Crossfeed processor should execute before the limiter so that any level changes introduced by stereo blending are still protected by the limiter. This ordering follows common DSP practice.

---

1. Crossfeed Processor

Create a dedicated Crossfeed processor.

Do not implement a simple left/right mix.

Implement a frequency-dependent crossfeed suitable for headphone listening.

The processor should preserve stereo width while reducing unnatural channel isolation.

---

2. Stereo Matrix

Create a reusable stereo matrix framework.

Future processors should be able to reuse it.

Examples:

- Crossfeed
- Stereo Width
- Mid/Side processing
- Stereo Rotation
- Balance

Avoid processor-specific implementations.

---

3. Crossfeed Parameters

Support:

- Enable / Disable
- Bypass
- Crossfeed Amount
- Crossfeed Cutoff Frequency
- High-Frequency Compensation
- Stereo Width Compensation

Parameters must update safely during playback.

---

4. Processing Model

Implement:

- frequency-dependent channel blending
- low-frequency crossfeed
- high-frequency compensation
- equal perceived loudness
- stereo image preservation

Avoid mono collapse.

Avoid phase artifacts where possible.

---

5. Thread Safety

Audio thread:

- no locks
- no heap allocations
- deterministic execution

Control thread:

- lock-free parameter updates
- atomic state updates where appropriate

---

6. Performance

Optimize for:

- SIMD-ready implementation
- reusable buffers
- zero unnecessary allocations
- cache-friendly memory layout

---

7. PlaybackManager

Expose all Crossfeed controls only through PlaybackManager.

The UI must never communicate directly with the native runtime.

---

8. Documentation

Document:

- Crossfeed algorithm
- Stereo matrix architecture
- Signal flow
- Parameter model
- Threading model
- Performance considerations

---

Validation
