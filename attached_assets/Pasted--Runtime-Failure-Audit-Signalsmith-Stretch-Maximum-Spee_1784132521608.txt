# Runtime Failure Audit — Signalsmith Stretch (Maximum Speed / Pitch)

IMPORTANT RULES

1. Jangan mengubah kode apa pun.
2. Jangan membuat patch atau proposal fix.
3. Jangan berasumsi.
4. Semua kesimpulan HARUS berdasarkan source code yang benar-benar dibaca dan log yang tersedia.
5. Jika suatu hal tidak bisa dibuktikan dari source maupun log, tulis "NOT VERIFIABLE".
6. Baca seluruh jalur eksekusi yang berkaitan sebelum mengambil kesimpulan.
7. Fokus pada penyebab playback berhenti saat Speed Playback atau Pitch Shift berada di nilai maksimum.

────────────────────────────────────────

## Bug yang sedang diinvestigasi

Saat slider Speed Playback atau Pitch Shift digeser hingga nilai maksimum:

- audio tiba-tiba berhenti
- playback macet
- UI Play/Pause berkedip sangat cepat
  (Play → Pause → Play → Pause → ...)
- kadang lagu berhenti total

Pada nilai normal semuanya berjalan dengan baik.

## Yang harus dicari

Periksa apakah pada nilai maksimum terjadi salah satu kondisi berikut.

### A. Frame calculation

Apakah:

- inputFrames menjadi tidak valid
- outputFrames menjadi 0
- outputFrames negatif
- outputFrames terlalu kecil
- carryFrames overflow
- carryFrames menjadi NaN
- carryFrames menjadi Infinity
- division by zero
- floating-point overflow
- integer overflow

Tunjukkan lokasi source yang membuktikannya.

────────────────────────────────────────

### B. Native

Audit:

nativeProcess()

nativeFlush()

nativeReset()

nativeDestroy()

Cari apakah:

- return error
- exception
- assert
- early return
- invalid pointer
- invalid handle
- nullptr
- buffer terlalu kecil
- output tidak ditulis
- output lebih sedikit dari yang diminta
- output kosong

────────────────────────────────────────

### C. AudioProcessor

Audit seluruh lifecycle.

Cari apakah:

- processor masuk bypass
- processor return NOT_SET
- processor reset
- processor recreate
- flush terjadi saat playback
- EOS muncul tiba-tiba
- handle berubah
- handle dihancurkan
- processor berhenti menerima queueInput()

────────────────────────────────────────

### D. AudioSink

Audit:

DefaultAudioSink

AudioProcessingPipeline

Cari apakah:

- starvation
- underrun
- ConfigurationException
- AudioSinkException
- empty output buffer
- pipeline berhenti memanggil processor

────────────────────────────────────────

### F. Playback loop

↓

pause()

↓

play()

↓

────────────────────────────────────────

### G. AudioTrack

Cari apakah:

- AudioTrack stop
- AudioTrack underrun
- AudioTrack flush
- AudioTrack write gagal
- AudioTrack menerima buffer kosong

────────────────────────────────────────

### H. MediaSession

Audit apakah MediaSession atau TransportControl mengirim:

pause

play

stop

berulang-ulang akibat suatu callback.

────────────────────────────────────────

### I. Extreme parameter safety

Audit seluruh kode Signalsmith.

Cari apakah library mempunyai:

- documented limit
- undocumented limit
- assertion
- undefined behaviour
- invalid ratio
- invalid pitch
- invalid speed
- maximum block limitation
- latency limitation
- FFT limitation

untuk nilai Speed Playback maupun Pitch Shift maksimum.
