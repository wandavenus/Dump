# 1. FIX WAJIB

## HIGH-1 — File Descriptor Leak

Perbaiki fd leak pada seluruh fungsi berikut:

- `WriteReplayGainTagsFd()`
- `RemoveReplayGainTagsFd()`
- `RestoreMetadataRegionFd()`

Kasus yang harus diperbaiki:

```cpp
TagLib::FileStream stream(fd, ...);

if (!stream.isOpen()) {
    ...
}
```

Pastikan apabila `TagLib::FileStream` gagal mengambil ownership fd (`fdopen()` gagal), fd asli tetap ditutup sehingga tidak terjadi file descriptor leak.

Pastikan solusi tidak menyebabkan:

- double close
- double fsync
- ownership conflict

Gunakan solusi yang paling aman sesuai lifecycle TagLib.

# 3. Double Write Permission Check

