# DSP Audit — 2026-08-02

## Scope

Audit seluruh jalur pemrosesan audio yang aktif pada player Media3/ExoPlayer:

- native C DSP pipeline,
- custom Media3 `AudioProcessor`,
- Android `AudioEffect`,
- playback speed/pitch and stereo width,
- startup/default-setting synchronization.

Target device: Xiaomi Mi 9T/K20, Android 11 / MIUI 12.

## Finding fixed

Four native processors were initialized with `bypass=0`:

| Processor | Native default before fix | Audible default parameters |
|---|---:|---|
| Compressor | Active | −20 dBFS, 4:1, soft knee |
| Crossfeed | Active | amount 0.3, 700 Hz low-pass, HF compensation |
| Limiter | Active | −1 dBFS ceiling |
| Soft clipper | Active | −0.5 dBFS threshold |

The Dart settings layer eventually pushed the correct persisted state, but the
Media3 service is created on demand. Therefore, first playback could begin
before `AudioEffectsService._pushEngineSettingsWhenReady()` completed. During
that window these processors could alter audio without user opt-in.

### Fix

The native initialization state for all four processors now starts bypassed
(`bypass=1`). Dart still explicitly pushes the persisted setting after service
readiness, so users who enabled a feature retain the intended behavior. Native
dispose/reset paths for compressor, crossfeed, and limiter also remain fail-safe
by restoring bypass.

## Important architecture details

1. `dsp_pipeline` registers processor slots with `enabled=1`. This is only
   pipeline dispatch registration; each processor's own bypass flag controls
   whether it changes samples.
2. `NativeDspAudioProcessor` fails open when the native runtime is unavailable
   or not initialized.
3. EQ, BassBoost, and LoudnessEnhancer are attached to the player session but
   their Android effect `enabled` state is restored from explicit settings and
   defaults to false.
4. ReplayGain is applied only by `_ReplayGainApplicator`; mode `off` explicitly
   calls native bypass. Its native initialization is already bypassed, so the
   startup race is safe.
5. Native loudness normalization and system LoudnessEnhancer have mutual
   exclusion in both directions.
6. Stereo widening is configured through `MediaCapabilitiesService`; its
   startup default is disabled and its processor matrix is identity.

## Remaining non-audible processing

The native gain stage starts not-bypassed, but its default is exactly `0 dB`
(linear gain `1.0`). The normal Dart startup path explicitly sets gain bypass
when the preamp is `0 dB`. For ordinary finite PCM this is transparent; it
only retains defensive non-finite sample sanitization while not bypassed.
