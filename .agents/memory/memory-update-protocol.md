---
name: Memory Update Protocol
description: User-requested instruction to update project memory after repository changes.
---

WAJIB memperbarui memory di akhir setiap sesi kerja yang mengubah repo (file
baru, refactor, parameter baru, perubahan arsitektur, dan sejenisnya).

**Why:** pengguna meminta.

**How to apply:** Sebelum menyelesaikan sesi yang mengubah repo, periksa memory
yang sudah ada dan perbarui topik serta indeks yang relevan tanpa membuat entri
duplikat.
