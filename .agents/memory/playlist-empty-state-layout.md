---
name: Playlist empty-state layout
description: Visual hierarchy and interaction pattern for the Library playlist page.
---

The Library playlist page follows the Apple Music-style empty state: a single AppBar title, rounded search field, a plus create-playlist row, a thin divider, then a centered empty-state message and full-width accent action button.

**Why:** The uploaded reference screenshot establishes this hierarchy as the intended visual target, replacing the earlier frequently-played/tile-grid interpretation.

**How to apply:** Keep the playlist page distinct from Library artist, album, and song views. Preserve the create action in both the plus row and the empty-state button, and keep user-created playlists searchable and tappable.
